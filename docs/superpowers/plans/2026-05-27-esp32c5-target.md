# ESP32-C5 Target Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `esp32c5` as a build target of `firmware/esp32-csi-node` with C6-parity Wi-Fi 6 / 802.15.4 / LP-core features and a gated 5 GHz CSI feasibility probe.

**Architecture:** Approach B (minimal expansion) from the spec — widen 3 external gates (CMakeLists `if(IDF_TARGET...)`, Kconfig menu `depends on`, per-file `#if defined(CONFIG_IDF_TARGET_ESP32C6)`) to also accept `esp32c5`. Keep `c6_*` filenames and `CONFIG_C6_*` symbol names unchanged. Reuse the S3 8 MB partition layout. Add `CONFIG_C5_5GHZ_CSI_EXPERIMENTAL` plus a runtime that switches the radio to UNII-1 and falls back to 2.4 GHz on driver error.

**Tech Stack:** ESP-IDF v5.4 (Docker image `espressif/idf:v5.4`), Kconfig, CMake, C, GitHub Actions.

**Spec:** [`docs/superpowers/specs/2026-05-27-esp32c5-target-design.md`](../specs/2026-05-27-esp32c5-target-design.md)

## Task 6: Create the `sdkconfig.defaults.esp32c5` overlay

This is the file that turns C5 into a buildable target. ESP-IDF auto-applies `sdkconfig.defaults.<target>` on top of `sdkconfig.defaults` when `idf.py set-target <target>` runs.

**Files:**
- Create: `firmware/esp32-csi-node/sdkconfig.defaults.esp32c5`

- [ ] **Step 1: Create the overlay**

Write the file with exactly this content:

```kconfig
# ESP32-C5 CSI Node — Target overlay (companion to ADR-110)
#
# Auto-applied by ESP-IDF when CONFIG_IDF_TARGET=esp32c5.
# Layered on top of sdkconfig.defaults — only the differences live here.
#
# Build:
#   idf.py set-target esp32c5
#   idf.py build
#
# Hardware: Electronic Cats / placa propia, ESP32-C5, 8 MB flash, no PSRAM,
# native USB-Serial/JTAG. See docs/superpowers/specs/2026-05-27-esp32c5-target-design.md.

# ── Target ──
CONFIG_IDF_TARGET="esp32c5"

# ── Flash & partitions (8 MB) ──
# Reuse the S3 8 MB partition table verbatim — partitions_display.csv is a
# chip-agnostic CSV; the "display" in the filename is historical (ADR-045).
# Rename to partitions_8mb.csv is a follow-up.
CONFIG_PARTITION_TABLE_CUSTOM=y
CONFIG_PARTITION_TABLE_CUSTOM_FILENAME="partitions_display.csv"
```

## Task 8: Wire the 5 GHz probe in `csi_collector.c`

Add a runtime block that, when `CONFIG_C5_5GHZ_CSI_EXPERIMENTAL=y`, calls `esp_wifi_set_channel` with the chosen UNII-1 channel after promiscuous mode is enabled, and falls back to the configured 2.4 GHz channel if the driver refuses.

**Files:**
- Modify: `firmware/esp32-csi-node/main/csi_collector.c` — insert block after `ESP_LOGI(TAG, "Promiscuous mode enabled (MGMT-only, RuView#396)");` (around line 479).

- [ ] **Step 1: Insert the probe block**

Locate the existing log line (currently ~line 479):

```c
    ESP_LOGI(TAG, "Promiscuous mode enabled (MGMT-only, RuView#396)");
```

Insert the following block immediately after it, before the `#if CONFIG_SOC_WIFI_HE_SUPPORT` block that builds `csi_config`:

```c
#if defined(CONFIG_C5_5GHZ_CSI_EXPERIMENTAL)
    /* C5-only 5 GHz CSI feasibility probe (ADR-110 spec §5).
     *
     * Default off. When enabled, switch the radio to a UNII-1 channel and
     * fall back to the 2.4 GHz csi_channel if the driver refuses (likely
     * outcome on ESP-IDF v5.4 preview). The Kconfig depends on
     * IDF_TARGET_ESP32C5 so this block is unreachable on other targets. */
    {
        const int probe_ch = CONFIG_C5_5GHZ_PROBE_CHANNEL;
        esp_err_t probe_err = esp_wifi_set_channel((uint8_t)probe_ch,
                                                    WIFI_SECOND_CHAN_NONE);
        if (probe_err == ESP_OK) {
            ESP_LOGI(TAG, "[C5 5GHz] channel %d set OK", probe_ch);
            csi_channel = (uint8_t)probe_ch;
            s_hop_channels[0] = csi_channel;
        } else {
            ESP_LOGW(TAG, "[C5 5GHz] set_channel(%d) failed (%s); falling back to 2.4 GHz ch %u",
                     probe_ch, esp_err_to_name(probe_err), (unsigned)csi_channel);
            (void)esp_wifi_set_channel(csi_channel, WIFI_SECOND_CHAN_NONE);
        }
    }
#endif  /* CONFIG_C5_5GHZ_CSI_EXPERIMENTAL */
```
